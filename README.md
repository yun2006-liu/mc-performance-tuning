\# Minecraft Java版 轻薄本性能调优方案

\## 项目介绍

针对荣耀MagicBook Pro16轻薄笔记本，基于PCL2启动器+Fabric加载器+Sodium渲染模组，优化Minecraft Java版游戏帧率。

整理完整的环境部署、参数调优、故障排查文档。



\## 硬件\&软件环境

\- 设备：荣耀MagicBook Pro16

\- 启动器：PCL2

\- 游戏版本：Minecraft Java 1.20.1

\- 模组加载器：Fabric

\- 性能模组：Sodium（钠，高性能渲染模组）



\## 操作步骤

1\. 使用PCL2下载游戏本体，PCL自动下载适配版本Java，无需手动安装JDK。

2\. 在PCL内安装对应游戏版本的Fabric加载器，\*\*加载器版本必须和游戏版本完全一致\*\*。

3\. 将Sodium模组jar包放入mods文件夹，启动游戏，在模组列表确认Sodium加载成功。

4\. JVM虚拟机内存分配：分配4096MB，避免内存溢出或者内存不足卡顿。

5\. 游戏画面参数优化：关闭阴影、降低渲染距离、关闭动态光影等特效，减少GPU负载，提升帧率。



\## 常见问题排查

1\. 模组不生效：Fabric版本与游戏版本不匹配，核对版本号。

2\. 游戏启动闪退：内存分配值超过电脑可用物理内存，降低分配内存。

3\. 提示缺少Java环境：PCL2自带Java下载功能，直接在启动器内自动安装。
